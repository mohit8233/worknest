# WorkNest extra features added

## Added
- Notifications system for users.
- Resume file upload: PDF/DOC/DOCX up to 5MB.
- Admin analytics cards.
- User confirmation email after apply.
- Featured jobs support with dynamic featured banner.
- Reject = delete from MongoDB and UI.

## Important install command
Backend now uses multer, so run:

```bash
cd backend
npm install
npm run dev
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```

## ENV
Copy backend/.env.example to backend/.env and fill values.
